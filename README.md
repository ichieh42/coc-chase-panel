# 追逐面板 · 克苏鲁的呼唤 7e

一个用于《克苏鲁的呼唤》第七版**第七章「追逐」**的跑团辅助工具。
打开网页即可使用，不需要安装，也不需要联网；所有数据只保存在你自己的浏览器里。

## 功能

| 页签 | 能做什么 |
| --- | --- |
| 角色卡库 | 创建、编辑、复制、删除角色卡与载具。支持调查员、NPC、怪物、载具四类；MOV、生命值上限、体格会根据属性自动算好，也可以手动指定 MOV |
| 追逐 | 建立追逐名单（追逐者 / 逃离者）、掷速度检定、查看地点轨、结算行动点、放置险境与障碍、处理冲突与战技、载具事故、随机险境、突发险境、躲藏、中途加入与换乘 |
| 规则速查 | 按页码整理的追逐规则条目，支持关键字搜索，忘记条款时随查随用 |
| 日志 | 自动记录每一轮的判定与结算（保留最近 600 条），方便回看或复盘 |

顶栏还可以：

- 切换**掷骰方式**——「自动掷骰」由工具帮你滚骰，「手动录入」用于你已经在桌上掷好、只需输入结果；
- **导出 / 导入 JSON**，用于备份或换设备；
- **清空本地**，重置为初始状态。

## 开始使用

双击 `index.html`，用浏览器打开即可（建议 Chrome、Edge、Firefox 或 Safari 的较新版本）。

基本流程：

1. 在「角色卡库」新建角色，填好 DEX、STR、SIZ、CON 与技能值，或新建一辆载具；
2. 切到「追逐」，把角色加入名单，并指定谁是**追逐者**、谁是**逃离者**，设置初始距离；
3. 逐个掷速度检定（或手动录入结果），MOV 会按结果自动加减；
4. 点「开始追逐」进入面板：轮到你时使用行动点移动、施放险境、攻击或使用战技，面板会提示当前可做什么；
5. 追逐结束后可查看日志回顾整场判定。

MOV 高于所有追逐者的逃离者会被判定为直接逃脱，工具会在开始前告知，不必强行开一场追不上的追逐。

## 数据保存在哪里

- 数据只存在**当前这台电脑的当前浏览器**里，关闭页面或重启电脑都不会丢，但不会自动同步到其他设备。
- 换浏览器、换电脑或清理浏览器数据会丢失记录，请先用顶栏的「导出 JSON」备份；在新环境用「导入 JSON」恢复。
- 导入时若遇到同名同类型的角色卡，会询问你是覆盖原卡还是另存一份副本。
- 使用无痕/隐私窗口时数据在关闭窗口后会被清除。
- 如果浏览器禁用了本地存储，工具会弹出提示并只在本次打开期间保留数据，记得及时导出。
